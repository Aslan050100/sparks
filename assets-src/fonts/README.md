# Fonts

- `Rubik-VariableFont_wght.ttf` — Rubik, SIL Open Font License 1.1 (free for web use).
- Druk Wide Cyr Bold is a commercial font and is **not** stored here. Only the web subset
  `src/static/fonts/druk-wide-bold.woff2` is committed. Make sure the brand's licence covers web use.
  To regenerate: `DRUK_FONT=/path/to/DrukWideCyr-Bold.otf python3 tools/prepare-assets.py`.
